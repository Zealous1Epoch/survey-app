关键技术知识点

Next.js App Router

  • page.tsx = 页面，route.ts = API
  • layout.tsx 包裹子页面（共享布局）
  • [id] 文件夹 = 动态路由段
  • "use client" 标记客户端组件
  • 服务端组件可直接 import DB 模块
  • params 是 Promise，需 await

better-sqlite3

  • 同步 API — 无需 async/await
  • 比异步 sqlite3 快 2-5×
  • .prepare(sql).run(...) — 写操作
  • .prepare(sql).get(...) — 单行查询
  • .prepare(sql).all(...) — 多行查询
  • WAL 模式：写不阻塞读，高并发友好
  • 外键需手动 PRAGMA foreign_keys=ON

Middleware 与 Edge

  • 跑在 Edge Runtime（类 CF Workers）
  • 不能访问 better-sqlite3 / Node API
  • 只能做轻量操作：cookie、redirect、rewrite
  • config.matcher 限制执行范围
  • httpOnly cookie 防 XSS 窃取

组件设计模式

  • 受控组件：QuestionEditor 接收 value+onChange
  • 状态提升：题目数据由页面持有，编辑器无内部状态
  • 不可变更新：onChange 传新数组，不修改原数组
  • 问卷编辑页 = 创建页的复用变体（预填数据）
